# Public Projects

Template projects you can adapt for your own use. Each subdirectory is a self-contained app with its own README and setup instructions.

## Projects

### [`golf-trip-template/`](./golf-trip-template)

A React Native / Expo app for real-time golf trip scoring. Supports two-team competition with live Firestore sync, player bios, and leaderboards.

**Stack:** React Native · Expo SDK 54 · Firebase Firestore & Storage · TypeScript · EAS Build

### [`financial-advisor-template/`](./financial-advisor-template)

A personal financial advisor powered by Claude AI. Ask plain-English questions about your finances from the terminal, or explore an interactive browser dashboard.

**Stack:** Python · FastAPI · React · Vite · Anthropic SDK · MCP

## Getting started

Each project has its own `README.md` with setup instructions. Clone the repo and navigate into the project you want:

```bash
git clone https://github.com/dylanbenach/public-projects
cd public-projects/financial-advisor-template   # or golf-trip-template
```
